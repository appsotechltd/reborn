# Fonts

Latin subsets of two SIL Open Font License 1.1 fonts, from Google Fonts:

- Source Serif 4 (Adobe), https://github.com/adobe-fonts/source-serif
- Inter (Rasmus Andersson), https://github.com/rsms/inter

Licence: https://openfontlicense.org (bundling with the renderer is allowed).
They are embedded so every render looks the same regardless of the machine.
